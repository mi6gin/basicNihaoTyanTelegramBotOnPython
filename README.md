Пользователь создаёт обращение и следит за ним в Telegram. Администратор отвечает, разбирает очередь, отправляет новости и смотрит журналы — всё там же, в боте.

## ✨ Возможности

### Для пользователя

- Русский и английский интерфейс с сохранением выбранного языка.
- Создание обращения с категорией и просмотр своих обращений.
- Диалог с администратором: текст, фотографии и документы.
- Статусы обращений, закрытие и оценка ответа «Помогли / Не помогли».

### Для администратора

- Очередь обращений, ожидающих ответа, и повторно открытых диалогов.
- Просмотр всех и открытых обращений по категориям; закрытые можно показать отдельно.
- Ответ пользователю и три заготовки ответов с предварительным просмотром.
- Рассылки новостей и рекламных сообщений с URL-кнопкой.
- Сводка по дням, просмотр записей, скачивание логов и списки пользователей и групп.
- Отдельный текстовый файл с подробностями ошибки, отправленный администраторам.

### Под капотом

- PostgreSQL, постоянные FSM-состояния и версионируемые миграции Alembic.
- Импорт старых SQLite-данных — однократный и безопасный при повторном запуске.
- Защита inline-кнопок: личные сценарии доступны только тому, кто их начал.

## 🚀 Быстрый запуск

### Docker Compose

Нужны Docker и Docker Compose. Создайте `.env`, укажите токен бота и ID администраторов:

```shell
cp .env.example .env
```

```dotenv
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=123456789,987654321
```

Запустите сервисы:

```shell
docker compose up --build -d
docker compose logs -f bot
```

Контейнер дождётся PostgreSQL, применит миграции, импортирует старые данные (если они есть) и запустит бота. База хранится в томе `postgres-data`, журналы и SQLite-файлы — в `bot-data`.

### Локально

Нужны Python 3.12+ и PostgreSQL. Создайте виртуальное окружение и установите зависимости:

```shell
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Для локального запуска задайте в `.env` адрес PostgreSQL с `localhost`, затем выполните:

```shell
alembic upgrade head
python -m scripts.import_sqlite
python main.py
```

`ADMIN_IDS` — Telegram ID администраторов через запятую. Если установить `DROP_PENDING_UPDATES=true`, накопившиеся за время простоя обновления будут удалены при запуске.

## 🗓 Журналы и приватность

- Все сообщения, которые Telegram передал боту, записываются по дням в `data/logs/YYYY-MM-DD.jsonl`; часовой пояс — Алматы.
- Сохраняются текст, данные отправителя и чата, действия с обращениями и ошибки. Для вложений сохраняются тип и метаданные, но не файл и не `file_id`.
- Токен бота в записях маскируется. Журналы старше лимита удаляются автоматически: остаётся максимум 30 дневных файлов.
- Ошибки `ERROR` и выше сохраняются с traceback и отправляются администраторам отдельными `.txt`-файлами. Чтобы получить файл, администратор должен сначала открыть личный чат с ботом.
- Администратор может выбрать день, просмотреть записи или скачать полный файл в личном чате. Реестр известных пользователей и групп хранится отдельно в PostgreSQL и не ограничен 30 днями.
- `data/logs` исключён из Git: сообщения могут содержать личные данные.

> Telegram не передаёт боту каждое сообщение группы: журнал содержит только доставленные обновления. Группы, где бот состоял раньше, попадут в реестр при следующем сообщении или событии участия.

## 📣 Рассылки

Из админ-панели можно отправить обычный текст или рекламное сообщение с кнопкой и ссылкой `http://` / `https://`. Получателей можно выбрать среди всех пользователей, только администраторов или отметить вручную.

Для ручного выбора есть список с именами, страницами, отметками выбора и поиском по username; можно выбрать до 100 человек. Перед отправкой бот показывает предпросмотр и число получателей, а после — статистику доставки. Рассылка ограничена по скорости. Пользователи, которые не открывали личный чат или заблокировали бота, могут быть недоступны.

При перезапуске незавершённая рассылка прервётся; уже доставленные сообщения не отменяются.

## 🛡 Безопасность в группах

- Нажимать кнопки меню может только пользователь, вызвавший `/start`.
- Переключение языка доступно в группе; поддержка и админ-панель — только в личном чате.
- Кнопка админ-панели в групповом меню не показывается, даже администратору.

## 🧪 Тесты

Установите тестовые зависимости и запустите проверки:

```shell
pip install -e '.[test]'
python -m pytest -q
```

Проверки кнопок и состояний не обращаются к Telegram и не запускают бота. Для интеграционных тестов хранилища задайте отдельную тестовую базу PostgreSQL — она будет очищена тестами:

```shell
TEST_DATABASE_URL=postgresql+asyncpg://bot:bot@localhost:5432/bot_test python -m pytest -q
```
